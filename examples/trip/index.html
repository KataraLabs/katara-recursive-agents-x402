One-day Boston itinerary

Implemented example · 12 spawned agents · 13 total agents · 20 fixture completion calls

Four coordinators each delegate two research tasks.

Command

Plan a one-day visit to Boston under $100 per person, excluding lodging and travel to Boston. Use public transport and official sources; label unverified hours or prices. Do not book anything.
npm run demo -- plan trip
npm run demo -- run trip --offline
npm run demo -- sources trip
npm run demo -- run trip --budget 0.75
npm run demo -- reconcile
npm run demo -- inspect

Agents and assignments

  • Master demo agent
    Plans specialist tasks and writes the final cited result.
    • Attractions coordinator

      Choose a compact set of sights grounded in official information.

      • Historic sights researcher

        Extract access and visit details for the Freedom Trail and Faneuil Hall.

        Sources: trail, faneuil
      • Public spaces researcher

        Describe accessible public spaces and library visit constraints.

        Sources: common, library
    • Food coordinator

      Propose meal stops without inventing menu prices.

      • Market researcher

        Identify documented food options and hours; flag missing prices.

        Sources: market
      • Area researcher

        Assess meal-stop location options from these sources; keep unsupported costs explicitly unknown.

        Sources: visitor, faneuil
    • Transport coordinator

      Suggest transport consistent with the official fare and route information.

      • Fare researcher

        Extract applicable fare amounts, units, and restrictions.

        Sources: fares
      • Route researcher

        Explain useful subway guidance and transfers; do not invent travel times.

        Sources: subway
    • Schedule coordinator

      Check opening hours and construct a feasible order with explicit assumptions.

      • Opening-hours researcher

        Extract opening hours and date restrictions, labeling anything unavailable.

        Sources: library, market
      • Budget researcher

        Identify verified costs and unknown costs. Do not claim the $100 cap is proven when prices are missing.

        Sources: fares, trail, market

What to look for

The travel budget is $100, separate from USDC inference spending. The default is a Boston day trip. Published prices are not bookings or guarantees of availability; unknown costs remain unknown.

A successful report contains every planned agent, cited child findings, and a cited master result. A partial report preserves useful sibling results and labels failed agents or missing sources. Research completion and payment confirmation are separate: run reconciliation until authorizations are confirmed or expire unused.

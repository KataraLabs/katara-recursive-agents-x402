AVAX activity briefing

Implemented example · 9 spawned agents · 10 total agents · 16 fixture completion calls

Three research leads each delegate to two researchers. Research covers Avalanche activity; inference payments use native USDC on Avalanche C-Chain.

Command

Produce an evidence-backed AVAX briefing for the past seven days: market activity, network observations, and ecosystem releases. Separate observations, estimates, and missing data.
npm run demo -- plan cryptocurrency
npm run demo -- run cryptocurrency --offline
npm run demo -- sources cryptocurrency
npm run demo -- run cryptocurrency --budget 1.25
npm run demo -- reconcile
npm run demo -- inspect

Agents and assignments

  • Master demo agent
    Plans specialist tasks and writes the final cited result.
    • Market activity lead

      Explain the supplied price and volume observations without extrapolating venue data to the whole market.

      • Price researcher

        Summarize the daily AVAX-USD candles over the supplied window. State the venue and incomplete-day limitations.

        Sources: candles
      • Volume researcher

        Compare available daily and 24-hour volume; distinguish AVAX volume from USD values.

        Sources: ticker, candles
    • Network observation lead

      Explain what the observed metrics establish and what they cannot establish.

      • Capital researcher

        Describe the seven-day TVL observations; TVL is not transaction throughput.

        Sources: tvl
      • Chain researcher

        Describe the observed mainnet block, timestamp, transaction count, and gas use. A single block does not prove weekly activity.

        Sources: block
    • Ecosystem release lead

      Summarize official releases inside the requested window.

      • Node release researcher

        Summarize the dated AvalancheGo release notes. Report an empty window honestly.

        Sources: avalanchego
      • EVM release researcher

        Summarize the dated Subnet-EVM release notes and source links.

        Sources: subnetevm

What to look for

The requested window is seven days. Coinbase statistics cover one venue, TVL measures capital, and the RPC observation is one mainnet block. Releases are limited to the fetched page. The output is a sourced activity briefing, not a trading strategy.

A successful report contains every planned agent, cited child findings, and a cited master result. A partial report preserves useful sibling results and labels failed agents or missing sources. Research completion and payment confirmation are separate: run reconciliation until authorizations are confirmed or expire unused.
